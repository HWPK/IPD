Data-Driven Carpooling Application for Sustainable Urban Mobility in London

Student: Syed Hussnain Ali Wasti (w1978727)  
Supervisor: Salma Chahed  

Project overview
This project investigates a data-driven approach to identifying feasible carpooling opportunities in London using open transport data and synthetic commuting patterns.

Aims and objectives
- Investigate limitations of existing carpooling solutions
- Use open data related to London transport networks
- Design a realistic commuter matching methodology
- Develop a prototype for visualising matched routes
- Evaluate feasibility and sustainability impact

Planned methodology
1. Extract London road network data (OpenStreetMap via OSMnx)
2. Generate synthetic origin–destination commuter trips
3. Preprocess and validate datasets
4. Cluster similar commuter journeys
5. Evaluate route compatibility and detour constraints
6. Visualise matched carpools
7. Evaluate efficiency and sustainability metrics

Repository status
At IPD stage, this repository contains project planning, documentation, and environment setup. Practical implementation will follow.

## Ethics
No real personal commuter data will be used. Synthetic data will be generated to reduce privacy and ethical risk.
